## Overview

AgentX brings mobile AI agent creation to Android and iOS. The platform lets users describe agents in natural language, connect external tools, and configure behavior for workflows that can operate with limited manual input.

Built with Flutter and designed around MCP support, AgentX offers a portable way to create structured, tool-connected workflows and add LLM-powered interactions to a mobile application.

---

## Capabilities

- Create custom intelligent agents for Android and iOS
- Specify an agent's role and purpose with natural language
- Add tools and connected services to agent workflows
- Configure agents to perform tasks autonomously
- Generate agent interactions through LLM-powered behavior
- Run the experience on both Android and iOS
- Use Flutter for cross-platform application delivery
- Support workflows centered on MCP integration

## Using AgentX

1. Launch the application on a physical device or emulator.
2. Add an agent and explain its intended purpose using natural language.
3. Select the tools and connected services the agent should access.
4. Set up the workflow to define how the agent responds and performs actions autonomously.
5. Run tests, refine the prompts or tool connections, and repeat as necessary.

To target a specific mobile platform, use the corresponding Flutter device command:

```bash
flutter run -d android
flutter run -d ios
```
